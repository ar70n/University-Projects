1.Qué estrategia has seguido para el cálculo de las frecuencias? ¿Qué otras alternativas se te ocurren para ese
cálculo? Indica sus ventajas e inconvenientes.

Para el cálculo de las frecuencias, hemos implementado el método getFrecuencia que recorre una lista de palabras de tal forma que cada vez que la longitud de una palabra corresponda con la longitud de entrada, aumentamos en 1 la frecuencia de dicha longitud.
Además, implementamos el método getLongitudesUnicas que devuelve el conjunto de las longitudes de cada palabra introducida. En el conjunto de longitudes, no se repite una misma longitud. De esta manera, obtenemos un conjunto de longitudes únicas. 
Luego, el programa principal recorre la lista de longitudes únicas, y por cada longitud obtiene su frecuencia con el primer método que implementamos. 
Otra alternativa para calcular la frecuencia sería utilizar la clase HashMap cuya clave sería la longitud y el valor sería la frecuencia de la longitud. De esta manera, se podría recorrer la lista de palabras una sola vez (con el primer método se recorría la
lista de palabras para ambos métodos getLongitudesUnicas y getFrecuencia) e ir actualizando el HashMap.
Además, con la clase HashMap, se podría obtener la frecuencia de una longitud específica de manera eficiente, ya que el acceso a los elementos es rápido. Una desventaja de esta alternativa es que podría requerir de más memoria, y más si la lista de palabras es muy grande.
En efecto, tendríamos que almacenar todas las longitudes y frecuencias de cada palabra en el HashMap. El rendimiento se vería afectado igualmente ya que en cada iteración sobre la lista de palabras actualizamos el HashMap.

2.¿Cómo implementarías un método getLongitudesRepetidas que devuelva las longitudes de las palabras que se
repiten al menos una vez? Con las palabras codigo casa gato, la salida debería ser únicamente la longitud 4 letras,
que es la única que se repite.

Para implementar el método getLongitudesRepetidas, bastaría con comprobar si una longitud ya se encuentra en el hashset del método getLongitudesUnicas. Esto se haría con el método contains que verifica si un elemento se encuentra en un hashset.
Si ese es el caso, podríamos añadir esta longitud repetida a un nuevo hashset, que contendría las longitudes repetidas.
La implementación del método sería la siguiente:

public HashSet<Integer> getLongitudesRepetidas() {
    HashSet<Integer> setUnicas = new HashSet<Integer>();
    HashSet<Integer> setRepetidas = new HashSet<Integer>();
      
    for (Integer valor : this.palabras.values())
        if (setUnicas.contains(valor)){
            setRepetidas.add(valor);
        }
        else{
            setUnicas.add(valor);
        }
    return setRepetidas;
}
