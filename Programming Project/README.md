# PPROG
## The Anthill Game
Autores: Antonio Moroño, Sergio Saúco, Miguel Campo y Jorge Jiménez

### Algunas notas:
· Para ver la documentaión en html: make mrundocs

· Para compilar solo anthill: make anthill

· Para compilar todos los tests: make TESTS

· Para compilar anthill y los tests: make

· Hay que dar permisos de ejecucion al script.sh, se puede hacer con: chmod +x script.sh

· Para guardar y cargar partidas NO hay que especificar las extensiones, el propio juego se encarga de gestionarlo. Por lo tanto, para cargar la partida save1.dat, habría que escribir load save1

### Notas a los desarrolladores:
*Para el que haga F9 que sepa que hay que incluir el comando turnon y turnoff en el graphic engine*
